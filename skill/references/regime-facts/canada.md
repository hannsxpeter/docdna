# Canada

## ITSG-33

- When ITSG-33 applies, select records for both departmental and information-system risk management. Use the Security Control Catalogue and Security Control Profiles as inputs. The suite contains an overview and Annexes 1 through 5. Source: [Canadian Centre for Cyber Security, ITSG-33](https://www.cyber.gc.ca/en/guidance/it-security-risk-management-lifecycle-approach-itsg-33), verified 2026-08-05.

- Select the security assessment and authorization package and authority-to-operate rows before production. Annex 2 makes the authorization package the input to the authorization decision and names statements of assessment, residual risk results or a threat and risk assessment, and the operations plan as its minimum contents. Source: [Canadian Centre for Cyber Security, ITSG-33 Annex 2](https://www.cyber.gc.ca/sites/default/files/cyber/publications/itsg33-ann2-eng.pdf), verified 2026-08-05.

## Privacy impact assessment

- Select a privacy impact assessment for a new program or activity that handles personal information for an administrative purpose, for a substantial modification to such a program, when the responsible official determines one is warranted, or when an existing administrative-use program has no personal information bank. Source: [Treasury Board of Canada Secretariat, Directive on Privacy Practices, Appendix C](https://www.tbs-sct.canada.ca/pol/doc-eng.aspx?id=18309&p=C&section=procedure), verified 2026-08-05.

## Algorithmic Impact Assessment

- Select an Algorithmic Impact Assessment for an automated decision system covered by the federal directive. Complete it during design, complete it again before production, and publish the final results. Source: [Government of Canada, Algorithmic Impact Assessment tool](https://www.canada.ca/en/government/system/digital-government/digital-government-innovations/responsible-use-ai/algorithmic-impact-assessment.html), verified 2026-08-05.
